# AI Quiz Game

## Project Overview
A terminal-based quiz game about Artificial Intelligence, developed using Python.

## Features
- Start a quiz and answer multiple-choice questions
- Display available quizzes
- Track current score and highest score
- Add new quiz questions
- Save quiz questions and scores using JSON
- Handle invalid input

## Technologies
- Python
- JSON
- Git
- GitHub

## How to Run
Run the following command:

    python main.py

## Data Files
- `quiz.json`: Stores quiz questions.
- `state.json`: Stores the highest score.
